무엇을 계산하나요?

습구온도는 Stull(2011) 근사식, 이슬점은 Magnus 근사식으로 계산합니다. 추정 WBGT는 그늘에서 0.7×습구온도 + 0.3×기온으로 산출합니다. 직사광선 선택 시 일사량·풍속 자료가 없는 한계를 표시하면서 추정 WBGT에 2.5°C를 더합니다.

페이스 보정식

Ely, Vihma, El Helou 등의 대규모 마라톤 분석에서 확인된 고온 시 기록 저하와 비선형 경향을 토대로 열부하를 계산합니다. 여기에 경기시간 차이를 반영한 거리계수(5km 0.30, 10km 0.44, 하프 0.72, 풀 1.00), 기준 페이스의 작은 보정, 더위 적응계수를 적용합니다. 거리·페이스·적응 계수는 논문이 개인별 공식으로 직접 제시한 값이 아니라 앱용 보수적 추정 모델입니다.

권장 범위

중심값 주변의 불확실성을 거리와 열부하에 따라 약 ±20~30%로 표시합니다. 실제 일사량·바람·복장·급수·개인 발한량을 알 수 없으므로 단일값보다 범위를 우선해 판단하십시오.

꼭 확인하세요

실제 WBGT는 흑구온도, 일사량, 풍속이 필요합니다. 더위 적응, 체격, 복장, 급수, 코스에 따라 차이가 큽니다. WBGT 20°C 이상이면 기록보다 안전을 우선하고, 어지럼·오한·혼란·운동조절 장애가 있으면 즉시 중단하십시오.
